# Object Classification

### Goal

Classes: Cutlery, Hair Brush, Keys, Medication, Specs
Image dataset: Modified Dataset (Source: [https://www.kaggle.com/datasets/humansintheloop/dollar-street-dataset]) 

### Dataset info

* cutlery (180 : 45)
* hair_brushes (211 : 52)
* keys (114 : 28)
* medications (173 : 43)
* specs (92 : 23)
