# Tranfer learning using ResNet18
Transfer learning is a technique where a model trained on one task is reused for a related task, especially when the new task has limited data.

Working:
1) *Pre-trained model*: Choose a model already trainged on a large dataset for a specific task which is  similar to your dataset. This model would have already learned all the general features (eg. edge feature, color feature, etc)
2) *Base Model*: The pre-trained model that you choose, is also called base model in our application. It already includes layers that have processed data to learn hierarchical representations, capturing low-level to complex features.
3) *Transfer Layer*: Identify layers in the base model that hold generic information applicable to your task. Generally lower layers captures general features such as edges and textures, while higher layers capture task-specific complex patterns.
4) *Fine-Tuning*: Fine-tune these selected layers with data from the new task. This process helps retain the pre-trained knowledge while updating parameters in later layer to learn the new dataset. This improves accuracy and adaptability.

## Residual Network (ResNet)
ResNet is a deep learning architecture designed to enable efficient training of very deep neural networks. It introduces skip(shortcut) connections, which allows the model to learn residual mappings instead of direct tranformations.

### Model Architecture:
- Tranfer Learning using ResNet on our dataset ([More Info](https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial))
- [ResNet paper](https://arxiv.org/pdf/1512.03385)
- More about ResNet [here](https://pytorch.org/hub/pytorch_vision_resnet/)
- 2 Approaches:
- - 1) Using ResNet as fixed feature Extractor
- - 2) Finetuning ResNet to our dataset 

#### Approach 1: Using ResNet as fixed feature Extractor
We are freezing all the layers of ResNet except the last layer of classifier. That means we will use original architecture of ResNet and modify only the last layer of classifier so that it learns to classify according to our dataset.

#### Approach 2: Finetuning ResNet
Here, we are unfreezing more layers of ResNet(more of the final layers) to see if the model classifies the objects much more accurately compared to 1st approach. We tried unfreezing 4th and 3rd layer in different experimentation.
